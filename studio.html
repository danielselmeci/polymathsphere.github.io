How a project runs

Discovery

We learn what you need, who it is for, and what limits we are working within: budget, timeline and existing systems.

Design

We plan the structure and design the interface first, so you can see and change things before they are built.

Build

We build with current, well-supported tools and share progress as we go.

Launch & handover

We launch, hand over documentation and access, and make sure you own what we built.

Working together

We take on a limited number of client projects at a time, so each one gets proper attention.

Every project runs under its own written statement of work, with an agreed scope, timeline and deliverables, and is built to be maintained after handover.
